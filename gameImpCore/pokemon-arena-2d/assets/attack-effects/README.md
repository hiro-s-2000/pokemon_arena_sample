# Attack Effects

戦闘中の技演出を、ポケモン本体のGIFとは分離して管理します。

- `source/`: 爪・牙・発射部位など、共通演出の透過PNGマスター
- `gif/`: ゲームが読み込む一回再生GIF
- `manifest.json`: ツール・検証向けマニフェスト
- `manifest.js`: `file://` 起動でも利用できるブラウザ向けマニフェスト

`attack_effects.js` は、元技名・技カテゴリ・ポケモンの体型・種族を使い、次の優先順位で演出を選びます。

1. 爪・斬撃
2. 牙・噛みつき
3. 手・拳／気弾
4. 口／くちばし
5. 砲台・ノズル
6. 全身・固有器官

全攻撃エフェクトは、添付動画のように技を判別できる「主形状1つ」を短尺で一度だけ見せる仕様です。ポケモン本体や攻撃の軌道を隠さない小さな表示を基本とし、加算合成や強い二重発光は使いません。Canvasによる補助描画も方向・飛翔・命中が分かる最小限に留め、汎用チャージ、長い残光、多重光輪、大量の火花を同じ攻撃へ重ねません。

爪・牙・体当たりを含む物理攻撃と、みず・でんき・くさ・こおり・かくとう・どく・じめん・ひこう・エスパー・むし・いわ・ゴースト・ドラゴン・あく・はがね・フェアリーの属性攻撃は、すべて同じ控えめな基準に揃えます。爪・牙・体当たり・属性パンチなどの接触技は、発動時にはGIFを出さず、実際に命中した位置へ主形状を一度だけ表示します。

16属性には、それぞれ固有の320×320／6フレーム・240msのGIFがあります。再生成スクリプトが図形から直接描画するため、色相変換に頼らず属性ごとの色と主形状を保ちます。爪・牙・体当たりも240ms、口・手・砲台・全身からの発動は200msの一回再生です。爪・牙が明示された物理技は専用シルエットを優先し、それ以外の属性技は該当する属性GIFを使います。96pxのポケモンでは、接触演出を90px以下、非接触演出を105px以下に抑えます。

非接触技は発射部位に短いチャージ兼放出演出を一度だけ出し、飛翔中は同じ属性色の簡易モチーフ、命中時は小さな光輪だけを表示します。同じ発射部位から連続発動した場合は古いGIFを置き換え、演出が積み重ならないようにします。カメックスの両砲台のように発射口が複数ある場合だけ、発射口ごとに1つずつ表示します。

Surfは使用者を中心に4本の水流と細い波紋が全周へ広がるCanvas演出です。Flamethrower、Hydro Pump、Thunder Shock、Thunderbolt、Thunder、地面を砕く技、Double Teamも、それぞれ専用の段階的なCanvas演出を使い、汎用GIFを重ねません。Hydro Pumpはカメックスなどの砲台を認識し、左右2本の白芯つき水流として描画します。攻撃判定の到達時間・半径・線幅は表示中の主形状と同期させています。

Whirlpoolの表示は半透明の細い渦線に抑えています。持続ダメージは対象ごとに最初の一度だけ命中演出を出し、その後の継続ヒットでは光輪や粒子を繰り返しません。`Heat Wave`、`Sludge Wave`、`Hurricane`など、名前に `wave` や風を示す語を含む非みず技を水演出へ誤分類しないよう分離しています。

`Thunder Fang`、`Wild Charge`、`Volt Tackle`、`Flare Blitz`などの接触技は遠距離ビームへ変換せず、接近して命中した位置だけに牙・属性・衝撃のGIFを出します。一方、`Sacred Fire`や`Pyro Ball`のような非接触の物理カテゴリ技は、小さな投射技として扱います。

## 再生成

Pillowを利用できるPythonで、リポジトリルートから実行します。

```sh
python3 gameImpCore/tools/build-attack-effect-gifs.py
```

## 検証

```sh
node gameImpCore/tools/test-attack-effects.js
```

新しい演出型を追加するときは、`manifest.json` と `manifest.js` の両方へ同じ項目を追加してください。テストは両マニフェストの一致、16属性の割り当て、全GIFの参照、発射部位分類、再生時間を確認します。
